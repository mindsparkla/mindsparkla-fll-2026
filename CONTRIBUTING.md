# 🤝 Welcome Team! 🎉

This is how we work together safely.

---

## ✅ Before Uploading Code

- Test your robot program first.
- Make sure it works.
- Name your file clearly (example: `mission1_v2.py`).

---

## 🚫 Do Not

- Delete someone else's code.
- Upload random test files into the `missions` folder.
- Push directly to `main` (Coach will help merge).

---

## 🚀 How We Add Code

1. Work in your mission folder.
2. Upload your code.
3. Ask for review before merging.

---

## 🧠 Remember

GitHub is like our team notebook.  
Be respectful and organized. 🤖
